
# Vihzhuo
> Vihzhuo is a drag and drop pagebuilder to manage pages in any PHP project.

Vihzhuo is a fork of [PHPagebuilder](https://github.com/HansSchouten/PHPageBuilder), please head over to that repository 
if you are looking for pagebuilder to integrate into your PHP projects for framework. This fork was made with needed 
changes that I needed for my clients.
